## 📌 Features

- 📱 **Fully Responsive Layout** — Optimized for mobile phones, tablets, and high-resolution desktop screens.
- 📑 **Single-Page Tabbed Navigation** — Instant, zero-reload tab switching between sections powered by vanilla JavaScript.
- 🎨 **Modern Dark Aesthetic** — Clean typography, custom CSS variables, subtle glassmorphism cards, and smooth micro-interactions.
- 🗂️ **Filterable Project Showcase** — Interactive category filters (All, Web Design, Applications, Web Development).
- 💬 **Interactive Testimonials Modal** — Clickable review cards with custom modal popups and backdrop blur.
- 📝 **Contact Section** — Form validation, input state management, and embedded location map.

## 🚀 Run Locally

No external packages, Node.js, or complex builds required!

### 1. Clone the repository
```bash
git clone https://github.com/shivampatle2004/portfolio_web.git
cd portfolio_web
```

### 2. Open in your browser
- Simply double-click `index.html` to open it in any browser, or
- Use VS Code's **Live Server** extension:
  ```bash
  # If you have VS Code installed
  code .
  # Right click index.html -> "Open with Live Server"
  ```
- Or run a quick Python local server:
  ```bash
  python -m http.server 8000
  ```
  Visit **`http://localhost:8000`** in your browser.
